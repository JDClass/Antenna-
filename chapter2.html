Topic 1 of 7

Two-element array

Two isotropic sources on the z-axis. Their spacing and relative phase decide where the waves add and where they cancel.

Array factor

The far field of an array of identical elements is the field of one element multiplied by the array factor (AF), which depends only on geometry and excitation. For two sources with spacing d and phase difference β:

AF = 2·cos(ψ/2)
ψ = kd·cosθ + β , k = 2π/λ
  • Maximum where the two waves arrive in phase: ψ = 0, ±2π, …
  • Null where they arrive in antiphase: ψ = ±π, ±3π, …
  • θ is measured from the array axis (z). θ = 90° is broadside, θ = 0° is end-fire.

N-element uniform linear array

N identical elements with equal amplitude, equal spacing d and progressive phase β. Choosing β points the beam broadside or end-fire.

AF = Σ e^{j(n−1)ψ} , n = 1 … N
AFₙ = sin(Nψ/2) / [N·sin(ψ/2)]
ψ = kd·cosθ + β
  • Main beam where ψ = 0, so cosθ₀ = −β/kd.
  • Nulls: θₙ = cos⁻¹[(λ/2πd)(−β ± 2nπ/N)], n = 1, 2, … (n ≠ N, 2N, …)
  • The first side lobe of a long uniform array is −13.26 dB, whatever N.
  • More elements → narrower beam and higher directivity.

Topic 3 of 7

Pattern multiplication

The total pattern is the element pattern times the array factor. Change either one and watch the product.

E(total) = E(single element at origin) × AF
|E|dB = |E_element|dB + |AF|dB
  • Valid for identical, identically oriented elements. The element pattern depends on the element type; the AF depends only on positions and excitations.
  • A null of either factor is a null of the total pattern.
  • Use it to design: choose the element so its null cancels an unwanted AF lobe, or choose the AF to sharpen a broad element pattern.
  • Example: a z-directed dipole has a null along the array axis (θ = 0°). Placed in an end-fire array, that null removes the end-fire beam. An x-directed dipole has its null at θ = 90° instead.
  • Real arrays also have mutual coupling, so engineers use the measured embedded element pattern.

Non-uniform excitation: binomial and Dolph–Chebyshev

Feeding the centre elements harder than the edges lowers the side lobes, at the cost of a wider main beam. Compare three distributions on the same broadside array.

UniformBinomialDolph–Chebyshev
Amplitudesall equalC(N−1, n)from TN−1(z)
Side lobes−13.26 dBnone (d ≤ λ/2)all equal, chosen level
Beamwidthnarrowestwidestnarrowest for a given SLL
Directivityhighestlowestbetween

Binomial

Coefficients are rows of Pascal's triangle, from expanding (1 + x)N−1. For N = 5: 1, 4, 6, 4, 1. With d = λ/2 the pattern has no side lobes at all. The amplitude ratio grows fast (N = 10 needs 126 : 1), which makes a feed network hard to build.

Dolph–Chebyshev

The array factor is matched to a Chebyshev polynomial, whose ripples are all the same height. You choose the side-lobe ratio R₀ and get the narrowest possible beam for that level. It is the optimum compromise between the two extremes.

R₀ = main lobe / side lobe (voltage ratio)
z₀ = cosh[ (1/(N−1)) · cosh⁻¹ R₀ ]
AF(ψ) = TN−1( z₀·cos(ψ/2) )

Uniform is the Chebyshev limit for SLL = −13.26 dB; binomial is the limit as the side lobes go to zero.

  • Compare directivities: the price of low side lobes is a small loss of directivity.

Topic 5 of 7

Planar (rectangular) array

Elements on an M × N grid in the xy-plane. Two progressive phases steer a pencil beam in both θ and φ.

AF = Sxm · Syn
Sxm = sin(Mψx/2) / [M·sin(ψx/2)]
Syn = sin(Nψy/2) / [N·sin(ψy/2)]
ψx = k·dx·sinθ·cosφ + βx
ψy = k·dy·sinθ·sinφ + βy
  • The planar AF is the product of two linear array factors, one along x and one along y.
  • To point the beam at (θ₀, φ₀): βx = −k·dx·sinθ₀·cosφ₀, βy = −k·dy·sinθ₀·sinφ₀.
  • Grating lobes appear where ψx = ±2πm and ψy = ±2πn. Keep dx, dy < λ/(1 + sinθ₀) to avoid them.
  • Directivity ≈ π·cosθ₀·Dx·Dy, where Dx and Dy are the broadside directivities of the two linear arrays. The formula assumes the array radiates into one hemisphere (elements over a ground plane). Isotropic elements radiate equally on both sides, so the exact value in the simulation is about 3 dB lower.
  • Applications: radar, satellite links, 5G massive MIMO panels.

Reading the u-v map

The map plots |AF| against u = sinθ·cosφ and v = sinθ·sinφ. Only the inside of the circle (u² + v² ≤ 1) is real space. Lobes outside the circle do not radiate. Steering slides the whole lobe lattice, so a grating lobe can enter the circle.

Topic 6 of 7

Circular array

N elements equally spaced on a ring of radius a in the xy-plane. The beam can be pointed in any azimuth with the same shape.

AF(θ,φ) = Σ Iₙ · e^{j[ka·sinθ·cos(φ − φₙ) + αₙ]}
φₙ = 2πn/N
αₙ = −ka·sinθ₀·cos(φ₀ − φₙ)
  • The phase αₙ cancels the path difference for the chosen direction (θ₀, φ₀), so all elements add in phase there.
  • The geometry looks the same from every azimuth, so the beam keeps its shape as it is steered through 360°.
  • A larger radius (ka) gives a narrower beam. Too few elements (arc spacing well above λ/2) raises the side lobes.
  • Uniform circular arrays have relatively high side lobes (about −8 dB for large rings), so amplitude tapering or more rings are common.
  • Applications: direction finding, radio navigation (VOR, TACAN), sonar, smart-antenna base stations.

Topic 7 of 7 · qualitative

Phased array antenna

A phase shifter behind each element tilts the combined wavefront. The beam moves in microseconds, with no moving parts.

How it works

If each element is fed slightly later than its neighbour, the wavefront leaves the array tilted. For scan angle θs measured from broadside, the required progressive phase is:

β = −k·d·sinθs
  • Beam broadening: the projected aperture shrinks, so HPBW grows roughly as 1/cosθs.
  • Scan loss: gain falls roughly as cosθs, and more at wide angles because of the element pattern.
  • Grating lobes: avoided when d/λ < 1/(1 + |sinθs|). For ±60° scan, d < 0.536λ.
  • Beam squint: phase shifters give the right phase at one frequency only. True-time-delay lines fix this for wideband systems.

Architectures

  • Passive (PESA): one transmitter, a phase shifter per element.
  • Active (AESA): a transmit/receive module per element, giving high power and graceful degradation.
  • Digital beamforming: each element digitised, so many beams can be formed at once in software.

Where they are used

Fighter and weather radar, 5G mmWave base stations and phones, low-earth-orbit satellite user terminals, and radio telescopes.
